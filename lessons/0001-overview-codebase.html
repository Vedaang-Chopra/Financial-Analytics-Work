Layered Architecture Recap

Recall the five‑layer model used throughout the project:

  1. Notebooks – inspection and visualization only.
  2. Public Interface – cli.py, registry.py, interfaces.py.
  3. Orchestration – workflow composition, no algorithmic logic.
  4. Core – implementation details, provider‑specific code.
  5. Schemas/Utilities – data contracts, helpers, and config objects.
